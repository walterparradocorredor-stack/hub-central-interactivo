Guía de Servidores Locales & CORS

Para aprovechar características avanzadas como la Sincronización de Scroll y el Modo Rayos X, el navegador requiere que el simulador y tu proyecto compartan el mismo puerto y dominio (CORS).

1. HTML Estático (VS Code Live Server)

Si tu proyecto es HTML estático y lo abres con Live Server (ej. en el puerto 5500):

  • Abre el simulador usando la URL de tu Live Server:
    http://127.0.0.1:5500/device-simulator/index.html
  • Ingresa la URL de tu sitio en el buscador del simulador.
